# Bachata S4 Emulator

This project is a staged Android emulator framework. It is built so additional PS3 compatibility work can be implemented progressively.

Current modules:
- CPU: Cell / PPU / SPU interface stubs
- Memory: guest-address maps and allocator stubs
- GPU: RSX abstraction and Vulkan/OpenGL placeholders
- Audio: Android audio backend placeholders
- Input: controller mapping stubs
- Filesystem: ISO / PKG / folder detection stubs
- Logging: structured log interfaces
